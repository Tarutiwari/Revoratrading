# ReVora Trading 📈

ReVora Trading is a web-based trading platform designed to provide trading tools, market insights, and AI-powered features through a simple interface.

## Tech Stack
- **Frontend:** Next.js, TypeScript
- **Backend:** Python, FastAPI
- **Database & Services:** SQL database, Redis

## Features
- User authentication
- Trading bots and signals
- Market news and insights
- Chatbot interface
- Trading tools and account management

## Getting Started
Clone the repository:

```bash
git clone https://github.com/Tarutiwari/Revoratrading.git
cd Revoratrading
```

Install frontend dependencies:

```bash
cd frontend
npm install
npm run dev
```

For backend setup, check `backend/README.md`.
